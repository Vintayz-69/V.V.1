# OUTREACH.md: Ready-to-use posts, emails and listings

**Written:** 10 November 2026. Goes with GROWTH.md section 3.

How to use this: copy a message, **change it into your own words**, fill in the [brackets], and send it. Never post the same text in many places: communities and Google both notice copy-paste promotion.

Rules for every message (LEGAL.md section 2):
- **Always say it's your site.** "I made this" or "I run this site".
- **Help first, link second.** The answer must be useful even if nobody clicks.
- Only claim what's true: free, no sign-up, runs in the browser, figures from GOV.UK / IRS / CRA / ATO with the date checked. Never "100% accurate", "official", "approved" or "trusted by thousands".
- Never tell someone what they *should* do with their money. Say "many freelancers…" or "an accountant can help you decide".
- Never pay for posts, links, upvotes or reviews.
- Facts below come from our data files (`public/assets/data/`). If a file changes, check these messages still match. Don't add the old 1099 figure or any other number that isn't in a data file.

## 1. Reddit and forum answers (daily)

**Where:** see GROWTH.md section 3. Read each community's rules on self-promotion first; some ban links completely, and then you just answer without one.

**How:**
1. Search the community for a recent question (last few days), e.g. "self-employed tax how much", "MTD", "1099", "how much to charge".
2. Open the matching calculator, type in *their* numbers, press **Copy link to these numbers**.
3. Answer like this:

> On £[profit] profit in England, a rough estimate is about £[total] in Income Tax and Class 4 National Insurance for 2026 to 2027, so around £[take-home] left, or £[monthly] a month. [One sentence explaining the main part, e.g. "The first £12,570 is tax-free, then 20% Income Tax and 6% Class 4 NI up to £50,270."]
>
> I run a free calculator site, and this link has your numbers already filled in, so you can change them: [link]
>
> It's an estimate. It doesn't include [what the tool doesn't cover, from the page], so an accountant is worth it if your situation is unusual.

Before posting, check every number in your answer against the calculator. Don't add facts you haven't checked.
