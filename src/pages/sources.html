Every tax rate, threshold and allowance used by our calculators comes from an official government source. This page lists each set of figures, the official pages it came from, the date we last checked it, and the tools that use it. It's built from the same data files the calculators read, so it always matches what the tools actually use.

How we check a figure

  1. Read it on the official page. We only use the IRS, GOV.UK (including HMRC), legislation.gov.uk, the Bank of England, the CRA and the ATO, plus other government sites where a tool needs them (such as the US Office of Personnel Management for federal holidays). Not blogs, forums or other calculators.
  2. Store it in one place. Each figure is written once, in one data file, with the link to its source and the date it was checked. The calculators read it from there, so no tool has its own copy that could go out of date.
  3. Test it against official examples. Where GOV.UK, the IRS or another source gives a worked example, it becomes an automated test. Every calculator also has at least three examples worked out by hand. More than 3,000 checks run before any change goes live.
  4. Say what it doesn't cover. Each tool page lists the cases it leaves out, so you know when to check with the official source or an accountant.

Some government sites block automated reading. When that happened, we confirmed the figure through the official site's own search results and, where possible, a second official source. The notes inside each data file say when this was done.
