How to use the UUID generator

  1. Pick version 4 or 7 and how many you need.
  2. Choose the format: uppercase, without hyphens, or in braces like some Microsoft tools use.
  3. Press "Copy all". Press "New UUIDs" for a fresh set.

What is a UUID?

A UUID (universally unique identifier, also called a GUID) is a 128-bit number used as an ID for database rows, files, orders and messages. It's written as 32 hexadecimal digits in groups of 8-4-4-4-12. The rules are in RFC 9562 (2024), which replaced RFC 4122.

  • Version 4 is 122 random bits plus 6 fixed bits that mark the version and variant. Use it when you just need an ID nobody can guess or repeat.
  • Version 7 starts with the time in milliseconds, then random bits. New ones sort after older ones, which keeps database indexes tidy. It shows when it was made, so don't use it where that should stay private.
xxxxxxxx-xxxx-4xxx-Nxxx-xxxxxxxxxxxx version 4 (N is 8, 9, a or b) tttttttt-tttt-7xxx-Nxxx-xxxxxxxxxxxx version 7 (t = milliseconds since 1970) Example v7: 0199d084-fb00-7… → 0x0199d084fb00 = 1,760,140,000,000 ms = 10 October 2025, 23:46:40 UTC

Frequently asked questions

Can two UUIDs ever be the same?

In theory yes, but with 122 random bits it's so unlikely that it isn't a practical concern, as long as they come from a good random number generator. Ours uses crypto.getRandomValues, the browser's secure generator.

Is a GUID the same as a UUID?

Yes. GUID is Microsoft's name for the same thing. Some Microsoft tools write them in uppercase and in braces, which the format options can match.

Should I use UUIDs as passwords or secret links?

Version 4 UUIDs are hard to guess, but they weren't designed as secrets. For passwords, use our password generator.
