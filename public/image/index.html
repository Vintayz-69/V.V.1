Frequently asked questions

Do the image tools remove location data from photos?

Yes. Every new picture is drawn fresh by your browser, so hidden details (EXIF data) such as GPS location and camera model aren't copied into it. We tested this with a photo carrying GPS data.

Is there a limit on file size or how many pictures?

There's no limit set by us. Very large pictures (over about 16 million pixels) are more than some phones can draw, so the tools tell you if a picture is too big.
