    What is a hash?

    A hash function turns any amount of data into a short, fixed-length fingerprint. The same input always gives the same hash, and changing a single character gives a completely different one, so hashes are used to check files haven't been damaged or changed.

    "hello" MD5 5d41402abc4b2a76b9719d911017c592 SHA-1 aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d SHA-256 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824 "Hello" (capital H) gives a completely different SHA-256: 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969

    SHA hashes come from your browser's built-in cryptography (crypto.subtle). Browsers don't include MD5, so we calculate it ourselves following its standard (RFC 1321), and we test it against a well-known implementation.

    Which hash is it? Check the length

    If a download page gives you a checksum without saying which kind, its length tells you. Each hash always has the same number of characters:

    HashCharactersBits
    MD532128
    SHA-140160
    SHA-25664256
    SHA-38496384
    SHA-512128512

    Capital and small letters don't matter: 2CF24D… and 2cf24d… are the same hash. The checksum box ignores the difference, and also ignores a label in front such as sha256:.

    Checking a file on your own computer

    You can also get a file's hash with tools already on your computer. Replace file.zip with your file's name:

    Windows (PowerShell) Get-FileHash .\file.zip -Algorithm SHA256 Windows (Command Prompt) certutil -hashfile file.zip SHA256 Mac (Terminal) shasum -a 256 file.zip Linux sha256sum file.zip

    Compare the result with the checksum on the download page. If even one character is different, the file isn't the one the publisher made: download it again from the official site.

    One letter changes everything

    Changing a single capital letter gives a completely different hash. That's what makes hashes useful for spotting changed files:

    MD5("hello") = 5d41402abc4b2a76b9719d911017c592 MD5("Hello") = 8b1a9953c4611296a827abf8c47804d7 SHA-256("hello") = 2cf24dba5fb0a30e… SHA-256("Hello") = 185f8db32271fe25…

    Type "hello" into the tool above to check these yourself.

    Frequently asked questions

    Which hash should I use?

    Use SHA-256 (or SHA-384 / SHA-512) for anything new. MD5 and SHA-1 are broken for security: people can make two different files with the same hash. They're still fine for spotting accidental damage, and many older download pages still list them.

    Can I hash passwords with this?

    Not for storing them. A plain hash of a password can be cracked quickly by guessing. Password storage needs a slow, salted method such as bcrypt, scrypt or Argon2, done by your server's software.

    Can a hash be turned back into the text?

    No. A hash is one-way. People can only guess inputs and compare hashes, which is why short or common inputs are easy to find.
