How to make a QR code

  1. Choose what it's for: a link or text, joining a Wi-Fi network, writing an email, or making a phone call.
  2. Fill in the details. The code updates as you type.
  3. Scan it with your phone's camera to check it works.
  4. Download it as PNG (for documents and websites) or SVG (for print: it stays sharp at any size).

How it works

A QR code stores text as a grid of black and white squares. Phones read the three big corner squares to find the code, then read the rest. Part of the grid is spare "error correction" data, so a code can still be read if a little of it is dirty, torn or covered. Our codes don't expire and don't send people through a tracking link: the code holds exactly what you typed.

Link or text https://vintayz.com/ Wi-Fi WIFI:T:WPA;S:Cafe Guest;P:sunny-day-42;; Email mailto:hello@example.com?subject=Quote%20request Phone call tel:+441632960123

The more you store, the more squares the code needs. A short link makes a small, easy-to-scan code, so shorten long links if you can. We leave a white border four squares wide around the code (the "quiet zone" the QR standard asks for), because scanners need it.

Frequently asked questions

Do these QR codes expire?

No. The code holds your link or text directly, so it keeps working for as long as the link itself does. There's no account or redirect that could be switched off.

Is my Wi-Fi password safe?

We never see it: the code is made on your device and nothing is sent anywhere. But the code itself contains the password, so anyone who scans it can join your network. Only put it where you'd be happy to share the password, such as for guests.

How big should a printed QR code be?

A common rule of thumb is to make the code at least a tenth as wide as the distance people will scan it from, and no smaller than about 2 cm (0.8 inches) across. Always print a test copy and scan it from where people will stand.

Can I use these codes for my business?

Yes. They're free with no limits and no watermark. Check the code works before you print a large batch.
