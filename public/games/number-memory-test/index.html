How to use the number memory test

  1. Press Start. A 3-digit number appears for a few seconds, with a bar showing how long you have left.
  2. Remember it. When it disappears, type it in and press Check (or Enter).
  3. If you're right, the next number has one more digit.
  4. If you're wrong, the test ends and shows the longest number you remembered.

How long each number is shown

Longer numbers stay on screen longer: 1 second, plus 0.4 seconds for every digit.

Long numbers are shown in groups of three, like 1 234 567, to make them easier to read. You can type them with or without spaces.

Tips to remember longer numbers

  • Chunk it. Remember 4 820 193 as three pieces, not seven separate digits.
  • Say it in your head as you read it: "four, eight-twenty, one-ninety-three".
  • Look for patterns: repeated digits, runs like 3-4-5, or numbers that mean something to you, such as a year.
  • Type it straight away. The longer you wait, the more you forget.

Frequently asked questions

What is a good score?

The fairest comparison is with yourself. Try the test a few times and see whether chunking and practice help you remember more digits.

Is this a medical memory test?

No. It's a game for fun and can't tell you anything about your health. If you're worried about your memory, speak to a doctor.

Is my score saved?

Only while the page is open. We don't use cookies or browser storage, so it's forgotten when you close or reload the page.
